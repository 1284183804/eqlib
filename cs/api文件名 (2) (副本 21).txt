SidechainSource：侧链来源，Internal 用自身信号，External 用外部信号。

MidSideMode：中侧模式，Stereo 直通，MidOnly 只留中间，SideOnly 只留两侧，MidSide 分别调增益。

DynParams：动态 EQ 每个频段的动态参数。

rz  对外 API：
API	用途
eqlib::setGlobalLogger(Logger*)	设置全局日志器，传 nullptr 恢复空实现
eqlib::getGlobalLogger()	获取当前日志器
Logger::trace/debug/info/warn/error	写日志

用途说明：DSP 核心默认不输出任何日志，零开销。你的 Qt 应用可以实现 eqlib::Logger 接口，把日志接到 qDebug。核心出错时通过日志接口占位，Release 下不产生任何代码。
csdl.h 参数队列  对外 API：这个类只给内部用，不暴露给 C API。

用途说明：单生产者（UI 线程）单消费者（音频线程）无锁环形队列。push 在 UI 线程调用，pop 在音频线程调用。队列满时 push 返回 false，调用方降级直写。 
sejlbq.h 双二阶滤波器  对外 API：Biquad<T> 是内部类，不暴露给 C API。

用途说明：双二阶 IIR 滤波器，支持 8 种类型。setParams 重新计算系数，processSample 逐样本处理，reset 清空状态。模板支持 float 和 double。
jhqhx.h + jhqhx.cpp 均衡器核心 对外 API：EqCore 是内部类，通过 C API 暴露。

用途说明：

    setBandGain 通过无锁队列传递，UI 线程安全。

    processSample 内做增益指数平滑和系数更新，避免滋滋声。

    consumeParamQueue 在 processBlock 开头调用一次，消费所有待处理参数。

    支持 float 和 double 两种处理路径。

eqlib/nbym/ppfx.h 用途：FftRadix2 是纯标准库实现的 radix-2 FFT。SpectrumAnalyzer 做流式频谱分析，逐样本输入，攒够一帧后计算频谱，输出 SpectrumFrame。
eqlib/nbym/ppfx.cpp 用途：纯标准库 radix-2 FFT + 流式频谱分析。processSample 逐样本输入，内部维护帧缓冲，攒够一帧算一次 FFT，带指数平滑。getFrame 读取当前频谱。
eqlib/nbym/zdjhq.h 用途：自动 EQ 核心。setReferenceCurve 设置目标曲线，feedSpectrum 输入当前频谱，computeResult 计算 7 个频段的增益，getResult 读取结果。
eqlib/nbym/zdjhq.cpp 用途：自动 EQ 实现。setReferenceCurve 设置目标，feedSpectrum 输入实测频谱，computeResult 算 7 段增益。参考曲线是必须的，不设置 computeResult 返回 false。
eqlib/nbym/zdzy.h 用途：自动增益核心。流式检测包络，与目标 dBFS 比较，计算增益，平滑后应用。带噪声门和最大增益限制。
eqlib/nbym/zdzy.cpp 用途：自动增益实现。逐样本检测包络，与目标 dBFS 比较，算增益，Attack/Release 平滑，限制最大增益变化，带噪声门。
eqlib/dwjk/eqlib/eqlib.h 用途：对外唯一头文件。第三期新增 ppfx_、zdjhq_、zdzy_ 三组 API，以及 eqlib_window_*、eqlib_fft_* 常量。
eqlib/nbym/dwjk.cpp 用途：C API 实现。第三期新增 ppfx_、zdjhq_、zdzy_ 三组函数。eqlib_handle 结构体新增 spectrum、auto_eq、agc 三个成员。

eqlib/nbym/bh.h 用途：模拟饱和核心。支持软削波、磁带、电子管、二极管四种非线性模型。
eqlib/nbym/bh.cpp 用途：四种饱和模型。softClip 是三次软削波，tapeSat 是 tanh 磁带，tubeSat 是非对称电子管，diodeSat 是对数二极管。mix 控制干湿比，drive 控制驱动力，output 控制补偿增益
eqlib/nbym/dtd.h 用途：多通道 + 多线程调度。processParallel 把帧范围分成 N 块，每块一个线程，调用用户传入的 lambda。getEffectiveThreads 根据配置和硬件并发数决定实际线程数。
eqlib/nbym/dtd.cpp 用途：线程管理。getEffectiveThreads 优先用用户指定线程数，否则用硬件并发数（最多 8）。processParallel 把帧范围分块，每块一个线程。
eqlib/nbym/wjdx.h 用途：WAV 文件读写。WavWriter 支持 float32、int24、int16 输出。WavReader 只支持 float32 和 int16 读取。
eqlib/nbym/wjdx.cpp 用途：WAV 写入和读取。WavWriter 支持 float32、int24、int16 输出，finalize 回填 RIFF 和 data 大小。WavReader 支持 float32 和 int16 读取。所有文件操作都用 std::FILE，纯标准库。

eqlib/dwjk/eqlib/eqlib.h 用途：对外唯一头文件。第五期新增 eqlib_file_* 常量，ypdr_ 音频导入 API，ypdc_ 音频导出 API。
eqlib/nbym/dwjk.cpp 用途说明：ypdr_load_mp3 直接解码 MP3 到内存，ypdr_get_info 读参数，配置 EQ/饱和/AGC，ypdc_process_and_save 一次性完成加载、处理、写 WAV。
eqlib/cs/cs_sejlbq.cpp 用途：验证 5 种滤波器类型。Peaking 在中心频率有增益，LowPass 对低频通过，HighPass 对高频通过，Notch 对中心频率衰减，AllPass 幅度不变。
eqlib/cs/cs_jhqhx.cpp  用途：验证 7 段 EQ 核心的参数设置、读取、处理、重置、参数队列消费。
eqlib/cs/cs_dtjhq.cpp 用途：验证动态 EQ 的自检测和侧链检测路径，读取阈值、比率、范围、模式。
eqlib/cs/cs_zdjhq.cpp 用途：验证自动 EQ 的参考曲线设置、启动/停止、喂频谱、计算结果、读误差。 
eqlib/cs/cs_ppfx.cpp 用途：验证频谱分析的初始化、流式喂样本、读取频谱帧、重置。
eqlib/cs/cs_zdzy.cpp 用途：验证自动增益的 boost 和 cut 两条路径，读当前增益和包络 dB。
eqlib/cs/cs_bh.cpp 用途：验证四种饱和模型的输出 RMS 和参数读取。
eqlib/cs/cs_dtd.cpp 用途：验证多通道、多线程调度、分块并行处理。processParallel 用 lambda 把帧范围分块。
eqlib/cs/cs_wjdx.cpp 用途：验证 WAV 写入、读取、回填 RIFF 大小、读回样本。
eqlib/cs/cs_dwjk.cpp 用途：验证 C API 全链路：创建、设置、EQ 处理、动态 EQ、饱和、自动增益、中侧、版本、销毁。
eqlib/nbym/xxwjhq.h 用途：线性相位 EQ 核心。用频率采样法设计对称 FIR 核，群延迟固定为 kernel_size / 2 个采样点。rebuild 根据当前 7 段参数重新计算核。
eqlib/nbym/xxwjhq.cpp  用途：用频率采样法设计线性相位 FIR。流程：在 N 个频率点采样 7 段 EQ 的幅度响应 → IFFT 得到零相位脉冲响应 → 循环移位 N/2 得到线性相位 → Blackman-Harris 窗 → DC 归一化。群延迟固定为 kernel_size / 2 个采样点。

核心公式：双二阶在频率 f 处的幅度用 z = exp(j*2πf/sr) 代入 H(z) = (b0 + b1*z⁻¹ + b2*z⁻²) / (1 + a1*z⁻¹ + a2*z⁻²) 计算。
eqlib/cs/cs_xxwjhq.cpp 用途：验证线性相位 EQ 的核大小、延迟、增益、重置

API	用途
xxwjhq_set_kernel_size	设置 FIR 核长度，256/512/1024
xxwjhq_get_kernel_size	读核长度
xxwjhq_set_band_type	设置频段类型 0~7

xxwjhq_set_band_q	设置 Q 值
xxwjhq_set_band_enable	启用/禁用频段
xxwjhq_get_band_*	读各参数
xxwjhq_reset	清空历史缓冲
xxwjhq_rebuild	强制重建核

延迟说明：latency = kernel_size / 2。512 抽头在 48kHz 下延迟约 5.33ms。线性相位无相位失真，但有预振铃。
